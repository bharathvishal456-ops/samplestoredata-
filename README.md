 Sample Store

A simple online shopping web application built using HTML, CSS, JavaScript, and Bootstrap. The project demonstrates a basic e-commerce website with product listings, shopping cart functionality, and a responsive design.

Features

 Home Page
 Product Listing
 Product Search
 Shopping Cart
 Responsive Design
 Contact Page

 Technologies Used

 HTML5
 CSS3
 JavaScript
 Bootstrap

 Project Structure

```
SampleStore/
│── index.html
│── products.html
│── cart.html
│── contact.html
│── css/
│   └── style.css
│── js/
│   └── script.js
│── images/
│── README.md
```

 Installation

1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/SampleStore.git
   ```

2. Open the project folder.

3. Run `index.html` in your browser.
